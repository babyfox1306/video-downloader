# ZavClip - All-in-one Viral Clip Toolbox

[![Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/babyfox1306/video-downloader)

ZavClip là bộ công cụ all-in-one để tạo và tải các viral clips. 5 tools trong 1!

## 🚀 Tính năng

- **Downloader** - Tải video từ TikTok, Instagram, YouTube, Twitter và nhiều nền tảng khác
- **Face Swap** - Hoán đổi khuôn mặt trong video (Coming in 24h)
- **Soundboard** - 500+ âm thanh viral sẵn sàng sử dụng
- **TTS Clip Maker** - Tạo clip với text-to-speech (Coming soon)
- **Meme Generator** - Tạo meme viral trong vài giây (Coming soon)

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Hosting**: Vercel

## 📁 Cấu trúc dự án

```
zavclip/
├── app/
│   ├── layout.tsx          # Root layout với navigation
│   ├── page.tsx             # Trang chủ với 5 feature cards
│   ├── downloader/          # Downloader tool
│   ├── face-swap/           # Face Swap tool (Coming soon)
│   ├── soundboard/          # Soundboard tool
│   ├── tts/                 # TTS Clip Maker (Coming soon)
│   └── meme/                # Meme Generator (Coming soon)
├── public/                  # Static assets
└── package.json
```

## 🚀 Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Mở [http://localhost:3000](http://localhost:3000) để xem kết quả.

## 📦 Deploy lên Vercel

1. Push code lên GitHub
2. Truy cập [Vercel](https://vercel.com)
3. Import repository từ GitHub
4. Vercel sẽ tự động detect Next.js và deploy
5. Done! 🎉
